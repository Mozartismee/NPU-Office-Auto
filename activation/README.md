# Office 授權

## 使用 v1

使用平常登入 Windows 的帳號，以系統管理員身分執行 [office-kms.bat](v1/office-kms.bat)。程式會辨識已安裝的 Office。找到多個版本時才會請你選年份。接著選 **1 校內授權網路**或 **2 學校 VPN**。校方提供的「NPU」無線網路無法直接授權 Office。[學校 VPN 下載與教學](https://www.npu.edu.tw/sub/faq/Details.aspx?Parser=26,32,311,,,,2145)

授權成功後，輸入 **1** 開啟提醒，或直接按 Enter 略過。啟用後，Windows 在目前帳號登入期間每日 **09:00** 檢查。剩餘 **7 天內**或已到期時，視窗會詢問「立即續期」或「稍後提醒」。選擇立即續期後，請確認 Windows 的管理員提示。

在首頁輸入 **R**，可使用下列功能。

| 選項 | 用途 |
| --- | --- |
| **11 查詢授權狀態** | 查看 Office 是否已授權、還剩幾天。 |
| **12 預覽到期提醒** | 查看提醒視窗。 |
| **13 移除到期提醒** | 關閉目前帳號的提醒。 |
| **14 開啟到期提醒** | 先前略過的人可在這裡補開。 |

## 試部署驗收

| 驗收項目 | 確認方式 |
| --- | --- |
| 校內認證 | 連上可用於 Office 授權的校內網路，選 **1**。用 **R → 11** 核對產品、授權狀態與剩餘天數。 |
| VPN 認證 | 先連上學校 VPN，再選 **2**，同樣核對授權結果。 |
| 開啟提醒 | 授權後先略過一次，再選擇開啟。開啟後，在工作排程器的「工作排程器程式庫」最上層確認 `NPU-KMS-Monitor-` 開頭的工作已啟用，每日 **09:00** 觸發。 |
| 實際執行提醒 | 在該工作按右鍵選「執行」，確認上次執行結果為 `0x0`。再查看 `%LOCALAPPDATA%\NPU-KMS-Monitor\monitor.log`，確認已讀到 Office 授權。 |
| 到期與續期 | 在即將到期或已到期的測試機驗證提醒是否跳出。分別測試「稍後提醒」及「立即續期」，用 **R → 11** 確認同一個產品的有效期是否延長。 |
| 關閉提醒 | 用原帳號選 **R → 13**，確認該帳號的提醒工作已移除。 |

### 目前驗證到哪裡

- 校內辦公室的 Windows 電腦已確認校方主機回覆成功，Office LTSC 2024 顯示已授權，約剩 180 天。當時的試作版誤報錯誤，v1 會重新核對同一套 Office 的授權狀態及有效期，再顯示結果。
- v1 的兩支指令碼已通過繁體中文 Windows PowerShell 5.1 語法檢查與 46 項檢查，涵蓋誤報、授權選擇、到期提醒與模擬排程。
- 試部署請依上表重跑 v1 的校內認證、VPN 認證及完整提醒流程，作為正式部署前的驗收。
